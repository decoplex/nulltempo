# Nulltempo — portfólio e tabela de serviços

Site estático responsivo da Nulltempo, com catálogo completo de Design Gráfico, Motion Design e 3D/VFX.

## Visualização

Abra `index.html` em um navegador. Os arquivos não dependem de instalação ou build.

## Conteúdo e interação

- Desktop: passe o mouse ou navegue pelo teclado para atualizar o painel de contexto.
- Celular: toque em um serviço para abrir o preview dentro da própria linha.
- Use os filtros para alternar entre Design Gráfico, Motion Design e 3D/VFX.
- Serviços, preços, descrições e regras ficam no array `services` de `script.js`.
- Clique diretamente em uma faixa de preço para adicioná-la ao resumo flutuante; cada serviço aceita uma opção ativa.
- O botão do resumo envia ao WhatsApp a lista, as opções de preço escolhidas e a soma.
- Em telas menores, os previews visuais são ocultados para priorizar leitura e seleção dos valores.

O botão de orçamento abre uma conversa no WhatsApp `+55 44 9814-2748`.

Os previews usam ícones vetoriais da biblioteca Phosphor Icons, distribuída sob licença MIT.
